快速上手

  1. 准备一个 AI 服务商的 API Key，例如 OpenAI、Anthropic、DeepSeek、智谱、xAI，或你常用的中转站。
  2. 打开 App，进入「设置 → 渠道 → 添加渠道」，选择服务商（中转站选「自定义 / 中转站」并填写接口地址），粘贴 API Key。
  3. 保存后 App 会自动拉取可用的模型列表。
  4. 回到首页新建对话，选择一个或多个模型，开始提问。

常见问题

XCAgent 收费吗？模型费用怎么算？

XCAgent 本身不提供 AI 服务，模型调用的费用由你的 AI 服务商按其价格向你收取，XCAgent 不经手任何费用。你可以在「设置 → 用量统计」查看各模型、各渠道用了多少 token。

添加渠道后没有模型 / 拉取模型失败

请检查：API Key 是否正确、是否还有余额；接口地址是否完整（OpenAI 兼容的中转站通常以 /v1 结尾）；接口格式（OpenAI / Anthropic）是否选对。有的中转站不提供模型列表接口，这时可以在渠道里手动添加模型名。

发送消息后报错

错误提示来自服务商，常见原因：401 Key 无效；402 / 429 余额不足或请求太频繁；404 模型名不对或该服务商没有这个模型。同一个模型配置了多个渠道时，App 会在出错时自动换下一个渠道。

联网搜索怎么用？为什么提示「不支持联网搜索」？

联网搜索使用各家服务商自带的能力（OpenAI、Anthropic、xAI、智谱、DeepSeek）。在输入框左边点放大镜开启。部分中转站不支持，这时 App 会按普通对话回答并给出提示。

语音输入中文里夹着英文，总是认错

系统语音识别一次只能识别一种语言。可以在「设置 → 语音输入」把识别方式改成「模型转写」，并选择一个支持语音转写的渠道和模型（例如 OpenAI 的 gpt-4o-transcribe、硅基流动的 FunAudioLLM/SenseVoiceSmall），中英混说就能识别正确。模型转写按服务商的价格计费。

如何在 iPhone、iPad 和 Mac 之间同步？

在每台设备上登录同一个 Apple 账户，并在「设置 → 数据」中打开「通过 iCloud 同步」。对话、文件夹、渠道、助手和提示词会自动同步；API Key 需要另外打开「同步 API Key」（通过 iCloud 钥匙串，端到端加密）。如果没有同步，请确认系统设置中 iCloud 云盘已开启。

换手机或者分享配置给别的设备

在「设置 → 数据 → 导出到剪贴板」导出渠道、模型和助手配置。包含 API Key 时需要设置一个密码，导出内容会用这个密码加密；在另一台设备导入时输入同一个密码即可。忘记密码就无法导入，我们也无法帮你找回。

开了应用锁，面容 ID 认不出来怎么办？

面容 ID 失败时可以改用设备密码解锁。应用锁可以在「设置 → 通用 → 应用锁」中关闭。

我的对话和 API Key 安全吗？

对话只保存在你的设备上（开启 iCloud 同步时也在你自己的 iCloud 里），API Key 保存在系统钥匙串。消息由你的设备直接发给你选择的服务商，不经过我们。详见隐私政策。

如何删除我的数据？

可以在 App 里删除单个对话，或在「设置 → 数据」清空所有对话；删除渠道会同时删除它的 API Key；删除 App 会移除设备上的全部数据。iCloud 中的数据可在系统「设置 → [你的名字] → iCloud → 管理储存空间」中删除。XCAgent 没有账号，也没有保存在我们这边的数据。

AI 的回答一定正确吗？

不一定。AI 生成的内容可能不准确、过时或带有偏见，请自行核实重要信息，不要把它当作医疗、法律、财务等专业建议。

Getting started

  1. Get an API key from an AI provider such as OpenAI, Anthropic, DeepSeek, Zhipu, xAI, or a relay you use.
  2. Open the app, go to Settings → Channels → Add channel, choose the provider (choose Custom / relay for a relay and enter its URL) and paste your key.
  3. After saving, the app fetches the list of available models.
  4. Start a new conversation from the home screen, pick one or more models and ask away.

FAQ

Does XCAgent cost anything? How are model costs billed?

XCAgent does not provide an AI service itself. Model usage is billed to you by your AI provider at its own prices; XCAgent never handles payments for it. See Settings → Usage for tokens used per model and channel.

No models after adding a channel

Check that the API key is correct and has credit, that the base URL is complete (OpenAI-compatible relays usually end in /v1), and that the protocol (OpenAI / Anthropic) is right. Some relays have no model list endpoint; add model names manually in the channel.

I get an error when sending a message

Errors come from the provider. Common causes: 401 invalid key; 402 / 429 out of credit or rate-limited; 404 wrong model name. When a model is set up on several channels, the app automatically fails over to the next one.

How does web search work?

Web search uses each provider’s built-in capability (OpenAI, Anthropic, xAI, Zhipu, DeepSeek). Tap the magnifier next to the input field to turn it on. Some relays don’t support it; the app then answers normally and shows a notice.

Voice input gets mixed Chinese and English wrong

System speech recognition handles one language at a time. In Settings → Voice input, switch to Model transcription and pick a channel and model that supports transcription (for example OpenAI gpt-4o-transcribe). Transcription is billed by your provider.

How do I sync between iPhone, iPad and Mac?

Sign in to the same Apple Account on each device and turn on “Sync with iCloud” under Settings → Data. Conversations, folders, channels, assistants and prompts sync automatically; API keys sync only if you also turn on “Sync API keys” (via iCloud Keychain, end-to-end encrypted). Make sure iCloud Drive is enabled in system Settings.

Moving to a new device

Use Settings → Data → Export to clipboard to export channels, models and assistants. If the export includes API keys you set a password that encrypts it; enter the same password when importing. We cannot recover a forgotten password.

App lock doesn’t recognise my face

If Face ID fails you can unlock with your device passcode. App lock can be turned off in Settings.

Are my conversations and API keys safe?

Conversations are stored only on your device (and in your own iCloud if you turn on sync). API keys are kept in the system keychain. Messages go straight from your device to the provider you chose, never through us. See the Privacy Policy.

How do I delete my data?

Delete individual conversations in the app or clear them all under Settings → Data. Deleting a channel also deletes its API key, and deleting the app removes all of its data from the device. iCloud data can be removed under Settings → [your name] → iCloud → Manage Storage. XCAgent has no accounts and we hold no data about you.

Are AI answers always correct?

No. AI-generated content can be inaccurate, outdated or biased. Verify anything important and don’t rely on it as medical, legal, financial or other professional advice.
