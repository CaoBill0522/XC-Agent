XCAgent

一个 App，接入你所有的 AI 模型。
让它们同时回答、接力分析、互相辩论。

One app for all your AI models.
Ask them side by side, chain them, or let them debate.

把多个模型放在一起用Use many models together

填上你自己的 API Key，就能使用 OpenAI、Anthropic、DeepSeek、智谱、xAI 以及各家中转站的模型。

Bring your own API key and use models from OpenAI, Anthropic, DeepSeek, Zhipu, xAI and any compatible relay.

接入任意模型Any model, any provider

支持 OpenAI Chat、Responses 和 Anthropic Messages 三种接口。填好 Key 自动拉取模型列表；多个渠道的同名模型自动合并、失败时自动切换。

OpenAI Chat, Responses and Anthropic Messages protocols. The model list is fetched once you add a key; the same model across channels is merged, with automatic failover.

多 Agent 并问Ask several at once

同一个问题同时发给多个模型，左右滑动对比，双击采纳最好的那个；后续对话只带上被采纳的回答。

Send one question to several models, swipe to compare, double-tap to adopt the best answer. Follow-ups only carry the adopted one.

接力 · 裁判 · 辩论Chain, judge, debate

让模型按顺序接力分析；或由裁判模型逐一点评打分、给出综合答案；或让几个模型轮流辩论，最后总结。

Let models analyse step by step, have a judge score every answer and write a combined one, or let them debate in turns and summarise.

联网搜索与工具Web search & tools

使用各家厂商原生的联网搜索，并标出来源。内置读取网页、计算器、当前时间，还能接入远程 MCP 服务器。

Native web search from each provider, with sources. Built-in web reader, calculator and clock, plus remote MCP servers.

识图、生图、文件Images & files

拍照或从相册选图让模型识别，用 gpt-image、DALL·E 等生成图片并保存；PDF 和代码文件直接发给模型阅读。

Send photos for the model to read, generate images with gpt-image, DALL·E and more, and attach PDFs or source files.

按住说话，中英混说Hold to talk

按住输入框说话，松手发送。可选用语音模型转写，「这个 style 我不喜欢」这样的中英夹杂也能认对。

Hold the input field to speak and release to send. Optional model transcription handles mixed Chinese and English.

iCloud 同步iCloud sync

对话、文件夹、渠道、助手和提示词在你的 iPhone、iPad 和 Mac 之间同步，存在你自己的 iCloud 里。

Conversations, folders, channels, assistants and prompts sync across your iPhone, iPad and Mac through your own iCloud.

随手就能问Always one tap away

主屏和锁屏小组件、Siri 与快捷指令「问 XCAgent」、系统分享面板、主屏图标快捷菜单。

Home and Lock Screen widgets, Siri and Shortcuts, the share sheet, and Home Screen quick actions.

用量与上下文Usage & context

按天、按模型、按渠道统计 token 用量；长对话可以自动压缩成摘要，省钱也不丢上下文。

Token usage by day, model and channel. Long conversations can be compressed into a summary automatically.

你的数据，只在你手里Your data stays yours

  • 没有账号，没有统计和广告 SDK，开发者不运营任何服务器。
  • 对话保存在本机，API Key 保存在系统钥匙串。
  • 消息由你的设备直接发给你自己选择的 AI 服务商，不经过任何中间服务器。
  • iCloud 同步是可选的，数据存在你自己的 iCloud 账户里。
  • 支持 Face ID 应用锁；代码完全开源，可以自己检查。
  • No account, no analytics or ad SDKs, and no developer-run servers.
  • Conversations live on your device; API keys live in the system keychain.
  • Messages go straight from your device to the AI provider you chose, with no server in between.
  • iCloud sync is optional and stores data in your own iCloud account.
  • Face ID app lock, and fully open source so you can check for yourself.
